# Inside the Ear Canal

Formal paper version of this disclosure, typeset in a two-column academic
format (Letter, 10pt Liberation Serif) for readers who want a citable,
printable document rather than the web write-up.

- **[Inside-the-Ear-Canal.pdf](Inside-the-Ear-Canal.pdf)** — the paper
- `paper.html`, `fig1-protocol.svg`, `fig2-chain.svg` — build source (rendered with [WeasyPrint](https://weasyprint.org/))

To rebuild after an edit:

```sh
weasyprint paper.html Inside-the-Ear-Canal.pdf
```

Content matches [`../earvision.md`](../earvision.md) and the CVE folders in
this repository; this version condenses some of the raw forensic detail
(e.g. one packet-layout table instead of three) in favor of the shorter,
denser style conventional for a paper.
